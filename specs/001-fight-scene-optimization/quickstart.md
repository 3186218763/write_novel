# Quickstart: 战斗场景回炉示例

**Feature**: specs/001-fight-scene-optimization
**Date**: 2026-05-29

## 快速上手：一场战斗的回炉前后对比

以下以第003章「菜鸟初战」莫宁梦 vs 针线魔女为例，展示回炉的核心改造方向。

### 当前状态（优化前）

自查评分：约 4-5/10

**已做对的**：
- ✅ 有记忆点（旧纽扣是弱点）
- ✅ 节奏句长控制不错（短句快攻）
- ✅ 有感官描写（霉味嗅觉、砖屑触觉）

**缺失的**：
- ❌ 敌人登场未遵循「先感知→露局部→显全貌」三步（魔女直接出现）
- ❌ 缺乏视角切换（全程莫宁梦主视角，没有敌人视角/旁观者视角）
- ❌ 缺乏场景破坏作为力量刻度（黑线扎墙之外，没有更多环境互动）
- ❌ 三要素配比失衡——氛围渲染不足，打斗动作占比过高
- ❌ 战后后果不够实（「右臂还在疼」但后续章节未明确承接）

### 回炉方向（不改变剧情）

**1. 敌人三步登场法（FR-008）**：

```
优化前：
→ 墙根的暗处飘出一堆碎布。

优化后（三步递进）：
→ 第一步（感知存在）：「霉味突然变浓。不是布偶的那种旧——是有什么东西在暗处醒了。」
→ 第二步（露局部）：「一根黑线从砖缝里钻出来，针尖泛银光。针尾拖着半截褪色红布。」
→ 第三步（显全貌）：「碎布从地上站起来。褪色粉布、泛黄白布、洗到发白的蓝校服料——粗黑线把它们胡乱缝在一起。针脚歪得厉害。一颗旧纽扣缝在脸的位置。」
```

**2. 增加视角切换（FR-007）**：

```
优化前：
→ 全程莫宁梦第一视角。

优化后（插入一次敌人视角，强化压迫感）：
→ 「碎布后面，那颗旧纽扣微微转了半圈。它不是在看她——是在认她的校服。这件校服它以前缝过。」
```

**3. 增加场景破坏（FR-009）**：

```
优化前：
→ 黑线扎进墙里，砖屑掉下来。

优化后（增加环境互动）：
→ 「黑线扎进墙里，砖屑掉下来——不止一处。整面墙的砖缝都在往外渗灰白色粉末。巷子像是被针线拆开的旧衣服。墙上的小广告纸从中间裂开，裂缝沿着针脚的走势往下爬。」
```

**4. 补强战后后果（FR-013）**：

```
优化前：
→ 「右臂还在疼。」

优化后：
→ 「右臂还在疼。她撩起破掉的袖口看了一眼——不是擦伤，是被黑线抽出一道三厘米的浅槽。没流血，但皮肤边缘微微发灰。她赶紧把袖子拉下来，握住吊坠的那只手还在抖。魔力见底的感觉像饿了两天——肚子不饿，但骨头里的力气被抽空了。」
```

## 核心原则

1. **不改剧情**：只改「怎么写」，不改「发生什么」
2. **加质不加量**：战斗字数可能增加 20-40%，但通过更好句子密度保持阅读节奏
3. **每次自评**：每场战斗回炉后跑一遍 10 项自查，不达标不回传
4. **Git 逐章提交**：一章一个 commit，出问题可精准 revert
