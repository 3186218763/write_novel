## 一、普通魔女

### 1. 针线魔女（性质：遗弃）
- **等级**: 普通魔女
- **辨识特征**: 碎布片拼合人形 + 粗黑线胡乱缝合 + 旧纽扣做脸
- **移动方式**: 瞬散瞬合（散成布片→另一位置重组）
- **战斗模式**: 黑线缠绕束缚；打散后遮蔽视线重组
- **弱点**: 重组间隙约半秒；纽扣是核心弱点
- **首次出场**: 第003章「菜鸟初战」
- **已知出场章节**: 第003章
- **耐受力**: **低**。外壳（布片）极脆弱一击即散但可重组；核心（纽扣）可被物理攻击砸停，需魔力光柱贯穿才能摧毁。

### 2. 锈蚀魔女（性质：腐烂）
- **等级**: 普通魔女
- **辨识特征**: 半流质融化的铁水 + 棕红锈壳 + 铁锈味+消毒水味
- **移动方式**: 贴地流淌，不抬起来，没有声音
- **战斗模式**: 锈水触手缠绕积重；命中溅出锈水麻痹
- **弱点**: 怕高温/高能冲击，魔力弹集中一点可炸散
- **首次出场**: 第005章
- **已知出场章节**: 第005章
- **耐受力**: **低-中**。比针线魔女略高（无核心弱点），3-6发魔力弹可消灭。影子属性对锈蚀有天然克制（魔女"认得影子"）。

### 3. 回音魔女
- **等级**: 普通魔女
- **辨识特征**: 悬浮嘴群+鱼群转向+共振刺脑
- **移动方式**: 嘴群如鱼群集群移动
- **战斗模式**: 声音共振干扰精神；嘴群散开合拢规避攻击
- **弱点**: 核心嘴动得最慢，精准切开即可全灭
- **首次出场**: 第010章
- **已知出场章节**: 第010章
- **耐受力**: **低**。单体嘴一击即碎，但核心隐藏在嘴群中提高了识别难度。差距在"识别难度"而非"耐受力"。

## 二、变异魔女

### 4. 天平魔女（性质：衡量）
- **等级**: 变异魔女
- **辨识特征**: 倒吊天平悬浮 + 秤砣心脏 + 横梁中央刻度表盘
- **移动方式**: 浮空自转，不追逐，制造力场规则
- **战斗模式**: 重力场偏折弹道 + 秤砣心脏膨胀加强重力/反转
- **弱点**: "平衡"——同时攻击两端秤砣，力场短暂崩溃露出核心
- **首次出场**: 第006章
- **已知出场章节**: 第006章
- **耐受力**: **中**。属于"高防御低血量"类型：重力场偏折使远程攻击完全无效，但核心（横梁竖缝）一旦被物理扣入破坏即瞬间塌毁。Shadow 五秒秒杀。

### 5. 荧幕魔女（性质：凝视）— 未在正文中正式出场
- **等级**: 变异魔女
- **辨识特征**: 碎屏手机悬浮 + 数据线滴黑黏液 + 屏幕滚动扭曲人脸
- **移动方式**: 永远正对目标
- **战斗模式**: 数据线弹幕 + 对视冻结魔力0.5秒 + 声音干扰
- **弱点**: 屏幕正面有对视冻结，背面无防御，绕后攻击电路板
- **首次出场**: 待确认
- **耐受力**: 中（设定文件，未经实战验证）。屏幕不可破坏（攻击穿过），电路板一击即毁。

### 6. 蜂巢魔女（性质：拥挤）— 未在正文中正式出场
- **等级**: 变异魔女
- **辨识特征**: 六角形蜂巢骨架 + 格子里挤满灰白影子
- **移动方式**: 固定于结界中心
- **战斗模式**: 灰影人海压手脚/抱腿/缠腰
- **弱点**: 蜂巢本体一直暴露但需先清开灰影路
- **耐受力**: 本体中低，灰影无限再生（约10秒一个）（设定文件，未经实战验证）。

## 四、旧圣历污秽/残响/领主

### 8. 傲慢污秽·王冠
- **等级**: 旧圣历强污秽（对应变异魔女~编号魔女之间）
- **辨识特征**: 灰白人形 + 头顶悬浮破碎王冠 + 裂开的黑口
- **移动方式**: 固定广场中央，靠声音和重压扩散领域
- **战斗模式**: 语言规则叠加重压，"承认你们低等"→抗拒者身体加重→跪下
- **弱点**: 王冠是规则核心——常规攻击只打裂，黑骑士暗影斩击从根部切断
- **首次出场**: 第030章
- **已知出场章节**: 第030章
- **耐受力**: **中高**。王冠再生2次（水刃打裂1次，合击打裂1次），直到黑骑士从根部斩断才被消灭。常规攻击只能裂无法断，需要高于其规则层级的暗影力量才能彻底破坏核心。

### 9. 失德圣女·海瑟 / 色欲污秽
- **等级**: 旧圣历堕落圣女（对应编号魔女级）
- **辨识特征**: 黑蜡人形 + 白纱遮发 + 白花/黑蜡/流泪的圣母像
- **移动方式**: 黑蜡散开重聚；借白花和歌声拖入幻象
- **战斗模式**: 喂给目标"你被需要"的幻象——不直接杀人，诱导自愿交出自己
- **弱点**: 名字和具体自我——喊真名可破幻象；切断与暴食连接可削弱
- **首次出场**: 第034/038章
- **已知出场章节**: 第034章, 第038章, 第039章, 第042章
- **耐受力**: **中**。身体可被打散无数次（黑蜡无限散开重聚），物理/魔力攻击对本体效果有限。真正弱点是名字锚定（呼名战术破幻象）和与暴食的连接（第042章切断连接后黑蜡碎开）。

### 10. 暴食残响·吞名者
- **等级**: 旧圣历残响（低于污秽领主）
- **辨识特征**: 臃肿黑影 + 肚子撑开栏杆 + 抓着名册不停咀嚼
- **移动方式**: 停留在记录密集处
- **战斗模式**: 咬记录→现实里有人失去名字锚点
- **弱点**: 即时记录+反复呼名可拖慢；莫宁梦影子可暂时压回快散的名字
- **首次出场**: 第036章
- **已知出场章节**: 第036章
- **耐受力**: **中**。魔力弹几乎无效（蚊子叮级），水刃可切但2秒愈合，圣铃金光可制停，影子有天然压制力。本章未被消灭，小白明确说"这只是残响，正主还没来"。

### 11. 暴食污秽领主
- **等级**: 旧圣历领主级污秽（城市级威胁）
- **辨识特征**: 城外黑色山丘 + 山丘上翻着被咬空名字的纸页 + 巨大咀嚼声
- **移动方式**: 压城——通过锚点定位而非移动进城
- **战斗模式**: 吞噬名字/祈愿/记忆——名字越响越易被定位
- **弱点**: 需要锚点定位→切断三条锚点（薇薇安名字+城名+照名镜）可使其失去定位退去
- **首次出场**: 第036章（残响预兆）、第039-041章（本体压城）
- **已知出场章节**: 第039章, 第040章, 第041章, 第042章
- **耐受力**: **极高**。无法被魔力弹/水刃/圣铃/影子直接伤害本体。全城名字共振可震开巨口。真正使其退去的方式是切断三条锚点定位，而非物理消灭。"不是死。是失去定位。它再也抓不住圣弥伦。"（第042章L275-277）
- **剧情功能**: 第三卷最终BOSS，推动莫宁梦完整影子形态首秀。

## 六、同等级耐受力一致性检查

### 普通魔女级 — 一致 ✓

| 维度 | 针线魔女 | 锈蚀魔女 | 回音魔女 |
|------|---------|---------|---------|
| 外壳耐受力 | 一击即散 | 可被击穿 | 单体一击即碎 |
| 核心弱点 | 纽扣（贯穿即死） | 外壳（连续命中可打穿） | 核心嘴（精准切开即全灭） |
| 再生/重组 | 是 | 否 | 是 |
| 被种子期单杀 | 是 | 是 | 否（唐雨救场） |
| 评级 | 低 | 低-中 | 低 |

**结论**: 基本一致。锈蚀魔女定为"低-中"因无核心弱点+锈水二次伤害，但仍在3-6发魔力弹范围。回音魔女核心隐藏在嘴群中提高了识别难度，差距在"识别难度"而非"耐受力"。

## 七、耐受力异常标记

### 异常 1：「中」评级内部差异较大 — 标记为 S3（低优先级）

"中"耐受力覆盖了三种截然不同的生存模式：
- **天平魔女**：高防御（重力偏折）极低血量（核心被抓5秒死）——"打不中但打中就死"
- **暴食残响**：中防御中血量快速愈合（水刃切开2秒堵上）——"打得中但愈合快"
- **海瑟**：几乎物理免疫（无限散开重聚）——"打不死的"

**建议**: 考虑在表格中增加"防御模式"列区分"偏折型"/"愈合型"/"免疫型"。不修改评级因三种模式对应三个不同等级（变异魔女/残响/堕落圣女）已有区分。

### 异常 2：黑骑士残影（第073章）"中"评级不准确

残影不是被打倒的，是"认出主人后归位消散"。建议标注为"非战斗消灭/归位型"而非评级。
