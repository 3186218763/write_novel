# Combat Checklist Reference Card

**Source**: `novel/研究/战斗场景参考.md` Section 11 + Section 零 (核心原则)
**Purpose**: 逐场战斗自查的统一评判标准 — 每项有明确的 ✓/⚠/✗ 判定依据
**Status**: Phase 2 基准参考卡

---

## 10 项自查清单（含判准）

### Item 1: 敌人辨识度 — 读者能记住敌人长什么样吗？

**硬约束** (参考手册 Section 一):
- 敌人登场遵循「先感知→露局部→显全貌」三步法
- 至少 2 项可识别特征（体型/轮廓、颜色/光效、声音/台词、移动方式、攻击特征）

**判准**:
- ✓ = 三步登场法完整 + ≥2 项特征明确，一句话能概括敌人
- ⚠ = 有特征描写但未完整走三步，或只有 1 项特征
- ✗ = "一个黑影"/"黑暗气息"/"发出嘶吼"等泛化描写，概括不出来

**参考**:
> 好的敌人：针线魔女 → "碎布拼的人形，黑线缝的，旧纽扣做脸"
> 差的敌人："一个黑影从暗处冲出来"

---

### Item 2: 与上一场敌人视觉不同 — 这场战斗的敌人和上一场比，视觉上不一样吗？

**判准**:
- ✓ = 外观/体型/颜色/材质至少有 1 项明显不同
- ⚠ = 同一类型敌人复用外观描述，仅微调
- ✗ = 连续两场战斗敌人外观雷同（如连续两个"黑影"）

**注意**: N/A 仅适用于全书首场战斗（第003章针线魔女）。

---

### Item 3: 与上一场敌人打法不同 — 打法上不一样吗？

**判准**:
- ✓ = 需要不同的应对策略（进攻方式/弱点/节奏有变化）
- ⚠ = 同类型敌人，战术微调但本质相同
- ✗ = 同样的攻击方式、同样的弱点逻辑、同样的节奏

**注意**: N/A 仅适用于全书首场战斗。

---

### Item 4: 有阶段性 — 不是从头到尾一个节奏

**硬约束** (参考手册 Section 二):
- 标准四段式：试探(15-20%)→压制(30-40%)→危机(10-15%)→反杀(20-25%)
- 骑士三层：物理战→能力战→终结技（碾压战可跳过第二层）
- 心理战三段：诱导→放大裂缝→选择时刻
- 最低要求：至少 2 个节奏变化（如 试探→反杀）

**判准**:
- ✓ = 完整四段式/三层/三段，节奏有松紧变化
- ⚠ = 有节奏变化但不完整（如只有试探+反杀，缺少压制和危机）
- ✗ = 从头到尾一个节奏，没有转折/升级/变招

**参考**:
> 500 字以下战斗可简化为两段/三段结构，四段式最低舒适线约 800 字

---

### Item 5: 对剧情有影响 — 起因/结果影响后续

**硬约束** (核心原则铁律三):
> 战斗必须影响后续——赢了要有回报，输了要有代价，平局也要有信息收获。

**判准**:
- ✓ = 战斗结果产生 ≥1 项后续影响（剧情推进/角色变化/信息获取/关系改变）
- ⚠ = 有后果但仅限该章内部，未衔接后续章节
- ✗ = 打完就完了，对后续无任何影响

---

### Item 6: 有一个记忆点 — 一句对话/一个反转/一个画面

**硬约束** (核心原则铁律二):
> 每场战斗只让读者记住一件事。

**判准**:
- ✓ = 能用一句话说清这场战斗的核心记忆点
- ⚠ = 有记忆点但不够突出，淹没在动作描写中
- ✗ = 说不上来这场战斗让人记住什么

**参考**:
> 好的记忆点：第003章 → "旧纽扣是弱点，被砖头砸中"
> 第006章 → "Shadow 五秒秒杀天平魔女"
> 第042章 → "影子学会留下名字"

---

### Item 7: 三要素涵盖 — 氛围+铺垫+动作

**强指导** (参考手册 Section 三):
> 好的战斗 = 氛围渲染(~1/3) + 解说铺垫(~1/3) + 打斗动作(~1/3)

**判准**:
- ✓ = 三项均有覆盖，配比大致合理（不要求精确到百分比，但不应某一项完全缺失）
- ⚠ = 缺 1 项（常见：缺少氛围渲染，直接从动作开始）
- ✗ = 只有打斗动作，无氛围无铺垫

**注意**: 
- 氛围包括：天气/光线/围观者反应/心理状态/战场环境
- 铺垫包括：招式背景/能力设定/战前信息——可在战前或战斗中分散交代
- 短战斗(300-500字)允许动作占比偏高，但氛围和铺垫不能完全为 0

---

### Item 8: 多感官激活 — 至少两种

**强指导** (参考手册 Section 五):
> 每段战斗至少激活两种以上感官。

**感官清单**: 听觉（命中声/环境音/变身音效）、触觉（冲击感/温度/肌肉反应）、嗅觉（战场气味）、体感（重力/眩晕/呼吸）

**判准**:
- ✓ = 激活 ≥2 种感官
- ⚠ = 仅 1 种感官（多数战斗只写视觉+偶尔触觉）
- ✗ = 只有视觉描写

---

### Item 9: 视角切换 — 不只一个角度

**弹性建议** (参考手册 Section 5.1):
> 500字战斗≈3-5次视角切换，1000字≈5-8次，1500字≈8-10次

**视角类型**: 主角主视角、近距离特写、武器/道具特写、旁观者视角、敌人视角、心理视角

**判准**:
- ✓ = ≥1 次非主视角切换（敌人视角/旁观者视角/道具特写）
- ⚠ = 有视角变化但停留在同一角色（从远到近/从动作到心理）
- ✗ = 全程单一视角，无任何切换

**注意**: 视角切换是弹性建议——短战斗/碾压战可略过，但中长篇战斗应至少有 1 次。

---

### Item 10: 删掉主线会断 — 必要性检验

**硬约束** (核心原则铁律一):
> 不为打而打——删掉这场战斗，看主线是否受影响。

**判准**:
- ✓ = 删掉战斗后主线断裂（剧情推进受阻/角色关系无法建立/信息无法获取）
- ⚠ = 删掉后主线不受影响，但战斗本身有塑造角色/建立世界观的功能
- ✗ = 删掉后完全不影响主线，属于"为打而打"

**注意**: Item 10 与 Item 5 互为验证——Item 5 检验"战斗是否有后果"，Item 10 检验"战斗本身是否必要"。

## 评分等级

| 通过项数 | 评级 | 回炉优先级 |
|---------|------|-----------|
| 10/10 | 优秀 | 免修 |
| 8-9/10 | 良好 | 轻度 |
| 6-7/10 | 一般 | 中度 |
| ≤5/10 | 差 | 重度 |

**核心战斗达标线**: 10/10（首次新类型敌人、BOSS战、有情感弧线的战斗）
**普通战斗达标线**: ≥8/10
**例外底线**: 至少满足 Item 1 + Item 6 + Item 5（辨识度 + 记忆点 + 后果），且例外比例 ≤15%

---

## 评判流程

```
1. Read 战斗段落（含前后 2 句过渡）
2. 逐项对照判准，给出 ✓/⚠/✗
3. 统计 ✓ 数量 = checklist_score
4. 按评级表确定回炉优先级
5. 回炉后重新自评，确认达标
```
