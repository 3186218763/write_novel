轻小说《我的骑士哥哥》，项目路径 e:/Py_Project/novel。妹妹莫宁梦是魔法少女（不知道哥哥的秘密），哥哥莫天是退役梦世界主宰者（已复出守护妹妹）。

**基调**：轻松搞笑为主，不虐不深沉。兄妹日常打打闹闹，哥哥爱逗妹妹，妹妹粘哥哥。

**核心红线**：每章至少2-3处莫天的精彩内心OS（吐槽风格），这是全书第一卖点。

**写作约束**：
- 第三人称有限视角（交替兄妹POV，但按章节固定）
- 一段一句，≤60字/段，对话独立成行，无空行，无「他说/她道」
- 禁用AI腔：禁用词全部替换，心理描写外化，不许有结尾升华

**当前进度**：第12章完成（2026-05-18）；第1-11章已就位，实际文件存在至第011章

**Why:** 用户明确要求轻松搞笑向，不走魔圆黑深残路线，兄妹互动是核心卖点。

**How to apply:** 每次写正文时确保：1) 莫天的吐槽OS充足 2) 兄妹互动占足够篇幅 3) 禁止AI腔和禁用词 4) 格式合规（一句一段）。
