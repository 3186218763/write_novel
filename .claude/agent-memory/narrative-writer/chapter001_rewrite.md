# 第001章重写

2026-05-22，按细纲完成了第001章「早上的战争」的全文重写，覆盖了之前的润色版。

**Why:** 原有的润色版是在旧正文基础上修改，而新版本需要严格按照更新后的细纲、角色设定（外貌/语言风格）、以及序章建立的人设锚点来写。

**How to apply:**
- 未来修改第001章时，以此为最新基准
- 角色出场外貌已按设定写入，后续章节涉及相同角色时保持一致

## 重写要点

1. **格式合规**：一段一句、无段间空行、对话用动作引出、内心独白用括号
2. **禁用词零命中**（「一丝不苟」为固定成语）
3. **穿越者暗示**：（哪个世界都一样。）嵌入梦世界巡视
4. **人物外貌严格按设定**：莫宁梦齐颈短发乱翘、林筱筱黑长直细框眼镜校服袖口挽半截
5. **莫天口头禅**「问题不大」自然嵌入独白
6. **章尾**：无升华式收尾，动作收束（洗碗→盖蛋饼→进冰箱）
