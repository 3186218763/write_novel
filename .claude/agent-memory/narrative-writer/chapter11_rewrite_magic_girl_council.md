第11章(闯入梦境·以及一片羽毛)根据三大敌人框架全面重写(2026-05-19)。

**核心变更**:
1. 污染来源从"梦魇碎片"改为"魔女会远程污染标记"——莫天捏碎时感知到"丝线"连接，发现是被人操控的
2. 新增关键世界观揭示：莫天发现"不是魔女，不是梦魇——有人在操控它"（三大敌人框架中最神秘的魔女会首次被感知到，但不点名）
3. 章尾新增魔女会端极简暗线（2-3句）——"被切断了""换个方向""她那个哥哥"
4. 羽毛掉落情节保留（为第12章"丢东西了"做铺垫）

**叙事结构**: 莫天主视角(55%)+宁梦副视角(30%)+魔女会极短插入(5%)+合拢收束(10%)

**Why:** 用户定义了三大敌人框架(普通魔女/魔女会/梦魇残余)，本章是魔女会线首次浮出水面的关键章节，需要克制处理——不命名不解释，仅让读者感知"还有人在关注这件事"。

**How to apply:** 后续涉及魔女会的章节需保持此克制风格——不详细不解释，用行动和简短对话暗示，让悬念自然积累。
