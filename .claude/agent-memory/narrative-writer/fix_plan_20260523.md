```
现在多了一个。
而这个菜鸟，恰好是莫天的妹妹。
她把手放下来。
（那个男生——果然不太对劲。）
（他的妹妹是魔法少女。）
（他自己是不是——）

```

她把手放下来。

### 3. [P6] 第009章 视角切换违规 — 行89-95

**问题**：同一课堂场景从莫天视角直接跳入唐雨内部感知（「水属性感知捕捉到一丝极淡的波动」「她记下了」），再切回莫天。

**修复**：将唐雨内部感知改为外部动作描写，全程保持莫天视角。

**修改前**（行89-95）：
```
第三排靠墙。
唐雨正低头记笔记，笔尖忽然顿了一下。
水属性感知捕捉到一丝极淡的波动——从靠窗的方向传来。
短到无法定位。
她不自觉往那个方向看了一眼。莫天正低着头，手指在膝盖上画着什么。
她收回目光。笔继续动。
但那一秒的波动，她记下了。
```

**修改后**：
```
第三排靠墙。
唐雨正低头记笔记，笔尖忽然顿了一下。
停了大概两秒。
然后她不自觉往靠窗的方向看了一眼。
莫天低着头，手指在膝盖上画着什么——他注意到了她的视线，手指停了。
唐雨收回目光。
笔继续动。
莫天把手指从膝盖上移开。
（差点被发现。）
```

### 8. [P4] 第005章 莫天未变身感知3km外魔力 — 行440-454

**问题**：莫天未变身人类形态下，3km外精确感知魔法少女体系水属性细节，缺乏铺垫。

**修复**：在行447「魔法少女。」前插入一行简短铺垫，利用他梦世界主宰的身份建立跨体系感知能力：

```
一丝魔力波动。
很弱。
一闪就收了。
像是有人点亮了一根火柴，然后立刻用手捂住。
不是梦魇。也不是影能。
魔法少女。
```

将「不是梦魇。也不是影能。」插入行446和447之间，暗示他能区分不同能量体系——因为他是梦世界主宰，对非梦世界能量有天然的「异物感」。
