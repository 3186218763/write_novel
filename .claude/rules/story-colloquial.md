# Story Colloquial Rules — 对话口语化规则

## 核心原则

**对话和内心独白必须说人话，第三人称叙述越文学越好。**

## 适用范围（严格限定）

此规则仅约束以下内容，不涉及第三人称叙述：

| 约束范围 | 示例 |
|---|---|
| **引导内对话**（双引号内容） | "我今天是个废人。" |
| **内心独白**（括号内内容） | （战术装死。） |
| **角色脑内自白**（无括号但明显是角色在想） | 完了完了完了。 |

**不约束**的第三人称叙述包括：场景描写、打斗动作、人物外貌、环境氛围、旁白过渡——这些可以并且应该使用文学修辞。

## 对话/独白禁止项

### 1. 禁止书面替代词（用老百姓的词）

写对话时，别让角色说书面语：

| 别写 | 写 |
|---|---|
| 便秘 | 窜西、拉不出屎 |
| 用餐、进食 | 吃饭 |
| 就寝、入睡 | 睡觉 |
| 愤怒、恼怒 | 气死了、火大 |
| 疲惫、倦怠 | 累死了、累瘫了 |
| 惊讶、诧异 | 吓我一跳、懵了 |
| 交谈 | 聊天、说 |
| 离开 | 走了、撤了 |
| 确实、的确 | 确实、真的 |
| 逐渐 | 慢慢、一点一点 |

### 2. 禁止端着的对话腔

- ❌ "我心中略感不安。"
- ✅ "我有点慌。"

- ❌ "这件事确实令人困扰。"
- ✅ "这事挺烦的。"

- ❌ "我对此深表遗憾。"
- ✅ "那太可惜了。"

### 3. 禁止对话中的万能文艺句式

- ❌ "命运的车轮已经开始转动了。"
- ❌ "我仿佛听到了命运的召唤。"
- ❌ "这一夜，注定无人入眠。"
- ❌ "某种难以言喻的情绪在心中蔓延。"

### 4. 禁止对话中绕弯子的心理描写

- ❌ "我不禁开始反思自己方才的言行是否妥当。"
- ✅ "我刚才是不是说错话了？"

- ❌ "我对未来的道路感到深深的迷茫。"  
- ✅ "以后咋整啊……"

### 5. 对话中禁止"如同/仿佛/宛如/便"等文学连接词

- ❌ "我感觉如同置身火海。"
- ✅ "我感觉像在火里。"

- ❌ "那便再好不过了。"
- ✅ "那就太好了。"

## 正确示例

> 莫宁梦往床上一倒："我今天是个废人。真的，彻底废了。帮我请假吧。"

日常口语，符合初中女生人设。

> （准头比上次好了。有进步。）

内心独白，简短直接。

> "你就不谦虚一下？"
> "在你面前谦虚，我怕你骄傲。"

兄妹拌嘴，自然随意。

## 错误示例（对话）

> "我对此感到十分困扰，昨晚的战斗确实消耗了我大量体力。"

→ 改："我好累啊……昨晚打那架累死我了。"

> "我内心深处有一种难以言喻的不安感。"

→ 改："我总觉得哪里不对劲。"

## 叙述端鼓励的文学修辞

以下写法请放心使用，甚至鼓励：

```
废弃大楼的天台。月光洒下来，照亮了一个少女的身影。
白色裙甲，淡蓝色光带环绕在手臂和脚踝周围，手里握着一把发光的长剑。
长发被夜风撩起，表情是前所未见的认真。
```

```
光与影的交错中，她的动作越来越流畅。
剑光在黑雾中划出一道亮线。
```

```
他站在虚空中，神情自在。亿万生灵的意识在这里交织、沉睡、做梦。
他一出现，整个空间的光都像是朝他这边偏了一度。
```

这些是叙述端的文学修辞，**完全不需要改**。

## 判断标准

写完后只问一句话：

> **这句对话或内心独白，说出来像不像人会说的话？**

- 像 → 过关
- 像朗诵/作文/翻译腔 → 重写
