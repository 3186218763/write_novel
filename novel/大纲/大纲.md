# 全书卷级大纲

> 暂定名：《我的骑士哥哥》
> 类型：无敌文 · 日常喜剧 · 魔法少女 · 假面骑士 · 恋爱迟钝（修罗场预备）
> 字数目标：约 80 章 × 4000 字 = 32 万字
> 目标情绪：轻松搞笑为主，战斗爽感为辅，感情拉扯调味

---

## 序章：日常之下（约 2100 字）

> 独立序章，置于第一卷正文之前。建立莫天「梦世界主宰 + 现实妹控」双面人设锚点。

## 第一卷：日常的裂痕（第 001-012 章，约 5 万字）

> 序章 + 12 章已完成设计与正文。

- **功能**：铺垫世界观·建立日常基调·引入核心冲突——妹妹成为魔法少女，哥哥发现并暗中守护
- **核心事件**：莫宁梦签约魔法少女 → 第一次战斗胜利（得意之夜的膨胀）→ 第二次战斗受伤 → 莫天确认身份 → 暗中守护（首次变身Shadow秒杀）→ 黑影救人余波 → 大学日常展开（唐雨登场+校园日常+分组伏笔）→ 唐雨与莫宁梦相遇（双重识别+醋意萌芽）→ 影子属性裂壳前兆+魔女会远观 → 魔女会登场（三方对视卷末收束）
- **起始状态**：莫天过着平静的退役日常，妹妹是普通中学生
- **结束状态**：莫天复出守护模式 ON，妹妹在成长中（影子属性裂壳），唐雨注意到莫天不简单，魔女会开始活动，林筱筱观察积累
- **情绪弧线**：温馨日常 → 菜鸟膨胀（喜剧）→ 受伤（心疼）→ 反转（哥哥知道一切）→ 爽（哥哥出手）→ 余波+好奇 → 轻松（大学日常）→ 感情种子（微妙）→ 风雨前兆（不安）→ 暗流涌动（卷末悬念）

## 第二卷：灯影之间（第 013-026 章，约 6 万字）

- **功能**：让魔女会进入日常，建立十三号橱窗与文学部双重压力线，推动莫宁梦从被动成长走向主动选择
- **核心事件**：沈知雾通过十三号橱窗接近莫宁梦 → 叶清棠以校刊、比赛、活动持续占用莫宁梦现实时间 → 唐雨正式介入训练与保护 → 莫天顺着黑灰线反查魔女会并识破沈知雾底色 → 魔女会正式出手 → 沈知雾半步倒戈 → 莫宁梦正式觉醒影子属性
- **起始状态**：莫宁梦只是裂壳状态，魔女会尚未真正伸手；莫天已把线放回魔女会据点
- **结束状态**：莫宁梦正式觉醒影子属性，沈知雾立场偏移但未正式脱离魔女会，莫天与沈知雾形成秘密结盟，唐雨彻底入局
- **情绪弧线**：轻微松动 → 双重消耗 → 被理解的错觉 → 失衡升级 → 复合爆点（出手 / 倒戈 / 觉醒）

## 第三卷：镜中旧圣历（第 027-042 章，约 6.5 万字）

- **功能**：异时空冒险卷·身份分层暴露卷·沈知雾脱离卷。通过梦境镜子遗物，把主角团卷入旧圣历圣弥伦，展开圣女体系、污秽历史、黑骑士传说、照名镜回归线与梦世界时间规则；卷末再坐实旧圣历圣弥伦约在现代五百年前。
- **核心事件**：沈知雾被魔女会清理，莫天救下她并形成秘密交易同盟 → 沈知雾发起老巷口火锅聚餐 → 魔女会暗示服务员触发梦境镜子遗物，众人坠入旧圣历圣弥伦 → 穿越第三天对抗傲慢污秽，黑骑士剪影重现 → 薇薇安入队，旧圣女体系展开 → 林筱筱亲眼见证莫宁梦变身并靠脑子救场 → 堕落圣女“色欲”与暴食污秽领主压城 → 沈听雨用真名救回沈知雾 → 莫宁梦完成完整影子形态，救下圣弥伦 → 众人回归现实过了一天多且正好半夜，薇薇安作为国际交换生和莫天远房亲戚暂住莫家，莫家杂物间后续整理为她的住处。
- **起始状态**：沈知雾半步倒戈但尚未脱离魔女会，莫宁梦刚觉醒影子属性，林筱筱仍不知道超自然真相，唐雨对影属性前辈线只有模糊线索。
- **结束状态**：沈知雾正式脱离魔女会，沈听雨离开旧街；林筱筱正式知情；薇薇安进入现代日常；莫宁梦完整影子形态首秀；唐雨掌握旧圣女和黑骑士线索并误判莫天与影属性前辈有关；魔女会因镜子反噬短期蛰伏，只怀疑莫天周边存在异常保护。
- **情绪弧线**：火锅日常 → 镜中坠落 → 找镜源回家 → 黑骑士传说重现 → 身份分层暴露 → 圣弥伦守城 → 薇薇安离乡 → 五百年前真相坐实 → 现实修罗场开启。

## 第四卷：日常回来了，但影子还没停（第 043-063 章，约 8 万字）

- **功能**：战后日常修复卷·现代适应卷·轻修罗场喜剧卷·莫天风险管控卷。把薇薇安真正放进现代生活，把第三卷的大战余波拆成“怎么重新过日子”的细小摩擦，同时让莫天从被动守护转向暗中接管风险。
- **核心事件**：莫天整理杂物间，薇薇安正式入住莫家 → 薇薇安学习手机、群聊、学校、现代礼仪，唐雨死宅属性暴露 → 众人重新吃一次商场火锅，试图覆盖老巷口阴影 → 沈知雾约莫天谈正事，被莫宁梦误会成咖啡店约会，轻修罗场启动 → 沈知雾与沈听雨展开新生活 → 普通团建中，莫天悄悄反向标记魔女会残余探子 → 他夜里摸清残余结构，清理明确越线者，留下可控渠道，以“影席”身份开始风险管控 → 第二次火锅在莫家真正团圆 → 薇薇安写下作文《我的家乡》，第一次正面承认圣弥伦已经成了历史 → 卷末镜面再次浮出旧圣历倒影，新的裂缝出现。
- **起始状态**：第三卷刚结束，众人从旧圣历回到现实不过一夜；薇薇安刚进莫家，沈知雾姐妹刚脱离旧街，魔女会因镜子反噬短期蛰伏。
- **结束状态**：薇薇安初步融入现代校园和主角团日常；沈知雾姐妹新生活落地；唐雨、林筱筱、莫宁梦与薇薇安的关系明显升温；莫天在无人知晓的情况下完成对魔女会残余的第一轮风险管控，“影席”传闻出现；镜面异常重新抬头，下一卷主线入口被轻轻推开。
- **情绪弧线**：回家局促 → 现代复健 → 轻修罗场升温 → 温柔安顿 → 暗线收网 → 火锅团圆 → 作文悼城 → 镜面再起。
