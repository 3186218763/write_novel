# 第一卷：退休骑士的日常不太平

## 核心信息
- **章节范围**：第 1-40 章
- **字数目标**：约 16 万字（平均 4000 字/章）
- **本卷定位**：展示无敌退休日常 + 妹妹的魔法少女新手期 + 两条世界线慢慢交汇

## 核心矛盾
莫天退役 2 年，已经是梦世界的主宰了，每天最大的烦恼是"今天给妹妹做什么"。但妹妹成了魔法少女这件事让他不得不重新上岗——而且是在不被发现的前提下。于是他的日常变成了：早上给妹妹做早餐 → 上学 → 暗中观察妹妹打怪 → 回家给妹妹做晚饭 → 深夜处理梦世界的小杂活。比退休前还忙。

## 结构拆解

### 单元剧划分

| 单元 | 章节 | 核心事件 | 功能 |
|------|------|---------|------|
| **A. 退休生活真忙** | 第1-6章 | 展示哥哥的无敌退役日常（做早饭+暗中看妹妹） + 妹妹的魔法少女新手日常（打怪+想哥哥） | 立人设+建双世界+定搞笑基调 |
| **B. 老父亲站岗** | 第7-14章 | 梦魇残留渗透现实→妹妹苦战→哥哥在远处看着（顺便吃了个面包）→信物掉落→兄妹日常心理战 | 两条线开始交叉 |
| **C. 妹妹的朋友们** | 第15-25章 | 朋友被梦魇残留影响→哥哥用碾压级手段处理（但更关心晚饭时间）→妹妹在现实中守护朋友 | 世界交汇小高潮 |
| **D. 日常与暗流** | 第26-35章 | 事件后的日常调整 + 一点隐藏势力的线索（但不影响搞笑日常） | 过渡+埋长线 |
| **E. 卷尾小钩子** | 第36-40章 | 关于莫天过去的第一条线索出现（稍微认真了一下下） | 钩住下一卷 |

### 本卷情绪弧线
莫天侧：始终平静/轻松/内心弹幕密集。妹妹侧：元气→困惑→小紧张→恢复元气→更坚定。
**总基调：笑着看完，偶尔"哇"一下，不会揪心。**

### ⭐ 本卷吐槽密度要求
- **每章至少2-3处莫天的精彩内心OS**（战斗章可略少但不可为零）
- 内心OS风格：短、密、生活化、一句见血
- 核心检验标准：读者会不会笑？会→合格。不会→加强
- 莫天的吐槽是贯穿全书的"第二条主线"，与剧情线并行
