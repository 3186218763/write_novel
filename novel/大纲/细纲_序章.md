# 细纲（序章）

## 序章：日常之下
- **核心事件**：
  1. 梦世界深夜——莫天立于虚空巡视，发现一处残余梦魇碎片，随手捏碎。展现主宰者的从容与孤独。
  2. 现实深夜——莫天从梦中醒来，去妹妹房间查看（踢被子/关窗/把掉地上的毛绒玩具捡起来放回床上）。无声的照顾。
  3. 次日傍晚——莫天买菜做晚饭，妹妹放学回家。兄妹餐桌互动——莫宁梦讲学校的事，莫天听着、吐槽、夹菜。温馨日常。
  4. 夜晚独处——妹妹睡后，莫天靠在床头望着天花板。内心独白：确认"这就是他要守护的东西"。
- **章首钩子**：意象预示 — 梦世界无垠的银色镜面之上，一道黑色身影立在虚空中。他脚下是亿万意识的碎片，像星星一样铺到视野尽头。
- **爽点**：
  - 梦世界中莫天随手碾碎梦魇残片——曾经需要苦战的敌人，现在连他的衣角都碰不到
  - 现实中对妹妹的温柔照顾——和梦世界中冷酷碾压形成反差
- **章尾钩子**：留白钩子 — 窗外月光铺在地板上。他闭上眼睛。意识边缘，梦世界的银色镜面微微一亮——又恢复平静。跟每天一样。
- **字数目标**：~2200字
- **情绪变化**：宏大孤独（梦世界巡视）→ 温柔（深夜照顾妹妹）→ 温馨（晚饭日常）→ 平静满足（独处收束）
- **涉及角色**：莫天、莫宁梦

### 场景分解

**场景一：梦世界（~500字）**
- 莫天立于梦世界虚空，巡视边界
- 发现一处残余梦魇碎片——无意识的，在角落蠕动
- 随手捏碎，内心OS"又是这种级别的残渣"
- 两年前需要全力战斗的敌人，现在连让他变身的资格都没有
- 巡视完毕，确认安全，意识回返现实

**场景二：深夜查房（~300字）**
- 凌晨三点，莫天自然醒来（在梦世界巡视后）
- 经过妹妹房间，门没关严
- 进去——被子踢到地上，窗户没关，毛绒兔子掉在床下
- 把兔子捡起来放回她手边，关窗，盖好被子
- 全程无声，动作轻得像影子

**场景三：次日傍晚·晚饭（~800字）**
- 莫天放学（大学）顺路买菜
- 厨房里切菜炒菜，莫宁梦放学回家
- 莫宁梦一进门就喊饿，被莫天吐槽"你每天回来第一句话都一样"
- 餐桌上莫宁梦讲学校的事——体育课跑了倒数第三、食堂宫保鸡丁太咸
- 莫天边听边吐槽边往她碗里夹菜
- 莫宁梦："哥你以后会不会不管我了" / 莫天："不会。你太费钱了，不管你我怕别人退货。"
- 温馨收束——莫宁梦主动收碗（罕见），莫天看着她的背影嘴角微翘

**场景四：深夜独处（~400字）**
- 妹妹房间灯灭了
- 莫天靠在床头，望着天花板上的月光
- 内心独白：梦世界的王也好，普通大学生也好——都是他
- 不需要任何东西来证明。守护这个家的日常，就是他现在全部的战斗
- 闭上眼睛。窗外的月光静静铺着
- 意识边缘，梦世界微微一亮——安全。又是普通的一天。

### 功能定位
- **对全书**：建立"无敌+妹控"的核心人设锚点，让读者从第一页就知道主角的底牌
- **对第一卷**：和第001章形成连贯——序章展示"日常是什么"，001章开始"日常出现裂痕"
- **对读者**：制造贯穿全书的戏剧反讽——读者知道莫天的真实实力，看他在大学装普通人的每一幕都有额外笑点
