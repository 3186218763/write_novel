## 核心关系：莫天 ↔ 莫宁梦

- **关系定位**：表面——打打闹闹的兄妹日常，哥哥爱逗妹妹，妹妹爱粘哥哥
- **隐藏层**：
  - 哥哥是假面骑士（妹妹不知），在梦世界登顶
  - 妹妹是魔法少女（哥哥知道但不说），在现实世界打怪
  - 妹妹对哥哥的感情正在悄悄越过兄妹的界限（她自己还没完全意识到）
- **力量体系**详见 [设定/世界观/力量体系.md](设定/世界观/力量体系.md)
- **日常画风**：
  ```
  早晨：哥哥叫起床 → 妹妹赖床 → 被掀被子惨叫 → 哥哥淡定做早餐
  中午：妹妹发消息"哥我中午不回来吃！"→ 哥哥回"好的"→ 妹妹"你就不好奇我跟谁？！"
  晚上：妹妹写作业遇到难题 → 哥哥讲一遍 → 妹妹"没听懂"→ 哥哥再讲 → 妹妹"还是不懂"→ 其实是故意的
  周末：妹妹缠着哥哥出门 → 路上蹦蹦跳跳 → 看到哥哥被女生搭话 → 立刻贴过去挽手臂 → "这是我哥有什么事吗"
  ```
- **核心张力**：信息差
  - 读者全知：知道哥哥是骑士（且已登顶梦世界），知道妹妹是魔法少女，知道哥哥在暗中守护
  - 哥哥视角：知道自己是梦世界主宰，知道妹妹是魔法少女，知道妹妹的小心思（但不戳破）
  - 妹妹视角：知道自己是魔法少女，不知道哥哥是骑士，觉得自己隐藏得很好
- **感情线基调**：妹妹单方面心动 → 日常拉扯 → 逐步意识到感情 → 全书结局揭示真相后进入新阶段。贯穿全文的暧昧拉扯，不虐，走甜向。
- **核心约束**：全书主线中哥哥的身份不能暴露 — **大结局揭示真相**

### 日常互动原则（搞笑向）

1. **兄妹斗嘴是日常**——妹妹先挑衅 → 哥哥淡定反击 → 妹妹跳脚 → 哥哥用一碗甜品或一个摸头杀收尾。循环往复
2. **妹妹的兄控行为**——抱手臂、蹭肩膀、找各种理由往哥哥身上靠、对哥哥身边的异性高度警觉
3. **哥哥的腹黑**——明明什么都知道（包括妹妹魔法少女和她的那点小心思），但装作不知道。偶尔用暗示性的话逗她看她脸红
4. **胜负关系**——表面上看妹妹经常被逗得跳脚，但关键时刻哥哥永远让着她。所以真正的赢家是妹妹
5. **永远和好**——不管闹成什么样，第二天早上哥哥还是会叫她起床，早餐还是会做她最喜欢吃的

1. **莫天 vs 梦魇**——全书主线冲突，但已无战事，剩下的都是轻松扫尾
2. **莫宁梦 vs 魔女**——副线冲突，现实世界的魔法少女战斗（正常难度线）
3. **莫天（内在）vs 自我认同**——融合存在带来的哲学层面的挣扎（长线人物弧线，但不影响轻松基调）
