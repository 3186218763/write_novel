# 林晚晴

> 妹妹成为魔法少女后的第一个引路人，同校学姐。魔法少女名号——**绯月**。
> 和唐雨的区别：绯月是运动系火爆学姐（高中同校），苍雪是外冷内宅型前辈（大学）。

---

## 基本信息

| 项目 | 内容 |
|------|------|
| **年龄** | 17岁 |
| **学校** | 锦都实验中学 |
| **年级** | 高中二年级（比莫宁梦高一年级） |
| **身份** | 魔法少女·萌芽期·**火属性** |
| **初登场** | 第4章《前辈没遇过》 |
| **魔法少女名号** | **绯月** |
| **契约兽** | 团团（火兔） |

## 外貌特征

- 黑长直扎**高马尾**，跑起来马尾一甩一甩的
- 眉眼带着一股不服输的劲儿，笑起来很爽朗
- 校服袖子经常撸到小臂，露出常年运动留下的线条
- 站着的时候习惯叉腰，坐着的时候一条腿搭在另一条腿上晃
- 魔法少女战斗服：赤红色系，裙摆有火焰纹路光效，手腕和脚踝有金红色光带

## 性格特征

**表面印象：火爆 · 直爽 · 运动系**

- **嗓门大笑得也大声**：跟熟人说话从来不压低声音，笑起来整条走廊都听得到
- **行动先于思考**：遇到事情先冲再说，打完了再想"刚才是不是太莽了"
- **好胜心强**：训练从不偷懒，比赛输了会复盘到赢回来为止
- **藏不住事**：情绪全写在脸上，撒谎的时候耳朵红得比莫宁梦还快
- **运动全能**：校田径部的王牌，短跑和跳远都是年级第一

**前辈的一面（对莫宁梦时）：**
- 虽然平时咋咋呼呼，但当前辈时会**故意收敛**，装出沉稳的样子
- 因为在她看来"前辈就该有个前辈的样子"——虽然装不过三句话就会暴露本性
- 第4章公园谈话时全程温和，是因为她**在端着**（想给后辈留个好印象）
- 熟了之后就不装了，会拍莫宁梦的肩膀说"走，请你吃烤串"

## 魔法少女设定

| 项目 | 内容 |
|------|------|
| **等级** | **萌芽期**（比妹妹高一级，距绽放还有距离） |
| **属性** | **火**——赤红色魔力，爆发型 |
| **战斗风格** | 高攻高速，近身猛攻型。先一套连招打满再考虑防御 |
| **契约兽** | **团团**（火兔）——赤红色毛发的兔子，虹膜金色，体型比一般兔子大一圈 |
| **契约兽性格** | 和主人一个模子刻出来的——暴躁好动，喜欢蹦跶，急了会喷火星 |
| **作为前辈的实力** | 足以指导种子期的新人，但对"怪味"没有认知 |

**能力倾向：**
- 火焰拳/火焰踢：将魔力集中在拳脚上，打击时附带灼烧
- 烈焰冲刺：直线高速突进，身后拖出一道火线
- 爆发加速：在极短时间内大幅提升速度和力量（但消耗大，不能持久）
- （以上为现阶段能力，到绽放期会有更多招式）

**战斗风格特点：**
- 和唐雨形成鲜明对比——唐雨是水+远程控制型，林晚晴是火+近身猛攻型
- 和莫宁梦（影子属性·灵巧陷阱型）也能打出配合

### 与莫宁梦的相遇
- 莫宁梦刚成为魔法少女不久，对付一只魔女时差点翻车
- 林晚晴路过直接冲上去一顿连招收尾，打完回头："你没事吧？"
- 之后两人保持联系，偶尔碰头交换情报
- 莫宁梦对林晚晴的第一印象："这个学姐好酷——"

## 角色功能

- **妹妹魔法少女路上的第一个引路人**——给了妹妹基础指导和精神支持
- **对比参照**：和唐雨形成强烈反差——林晚晴是火爆运动学姐（熟了之后），唐雨是冷面实力前辈（一直冷）
- **三人组化学反应潜力**：林晚晴+唐雨+莫宁梦同框时——一个火一个冰一个影子，光是性格碰撞就有笑点
- **世界观补充**：通过她的视角展示"普通魔法少女"的认知边界——她不知道梦魇、不知道魔女会，代表了大多数魔法少女的常态
- **出现频率**：偶尔出场，不过度占用篇幅（区别于唐雨的常驻定位）

| **莫宁梦** | 魔法少女前后辈·同校学姐 | 认识最早的前辈。熟了之后会勾肩搭背去吃烤串的关系 |

| **唐雨** | 不认识（听说过但无交集） | 不同学校圈子。唐雨是绽放期大佬，林晚晴是萌芽期菜鸟——如果见面，林晚晴可能会紧张 |

## 第4章已有戏份总结

- 公园长椅碰头交换情报
- 察觉到莫宁梦状态变好（"比以前稳了"）
- 被妹妹聊到"我哥做的饭太好吃了"时的表情逗到
- 确认自己从未遇到过"怪味"魔女
- 让妹妹"如果再遇到，联系我"
- **剧情视角注解**：第4章她全程温和，是因为当时在"装前辈"。如果熟了再同框，画风就不一样了。
