**为什么没有当场揭穿**
唐雨在010章结束时的心理状态：
1. 她确定莫宁梦就是她之前感知到并发送引导信息的那个种子期新人——但这是通过魔力气息辨认的，不是秘密渠道查到的信息
2. 她确定莫宁梦是莫天的妹妹——这个在现场就确认了
3. 两条信息在她脑海里完成闭环：莫宁梦的魔力气息 = 之前感知到的那次特殊波动 = 莫天的妹妹，但正文不再用等式链直说
4. 但她没有声张，原因：
   - 她没有证据证明莫天知道妹妹的身份
   - 直接挑明可能暴露她自己的更多信息
   - 她选择"知道了但不动作"——把信息收好，等更多线索浮出水面

**对暗处活动的感知**
- 011章感知到一种无法定位的压迫感——不是威胁信号，是"存在"，像云层后面有雷还没响
- 012章确定暗处有组织化活动（魔女会），但尚未掌握规模
- 决定提高巡逻频率

**近期目标**：处理薇薇安现代身份+追查旧圣女体系/黑骑士传说/影属性前辈线+重新评估完整影形后的莫宁梦+继续观察莫天异常

## 第二卷预备角色

### 沈知雾
- **定位**：十三号橱窗店主 / 魔女会边缘核心成员 / 第二卷前台接触人
- **当前作用**：负责接触、筛选、安抚、诱导新人魔法少女走向堕落
- **关键底色**：不是纯恶，她留在魔女会的根本原因与妹妹沈听雨有关
- **第二卷提醒**：她的立场偏移必须先从“护妹妹”开始，而不是直接从“喜欢莫天”开始
- **当前进度**：第三卷正式脱离魔女会，带沈听雨逃出旧街；已知莫天黑甲/黑影身份一层，与莫天形成保密和保护听雨的交易同盟；魔女会从一开始就没打算让她和听雨回来

### 沈听雨
- **定位**：沈知雾的妹妹，初中生
- **当前认知**：已亲眼接触超自然世界；知道姐姐处境危险但未掌握全部体系；见过莫天、莫宁梦、林筱筱、唐雨、薇薇安共同行动
- **功能**：沈知雾现实世界里最干净、也最不能失去的锚点；莫天识破沈知雾本质的重要入口
- **第三卷后提醒**：不要把她写成病弱苦情模板。她的高光是用普通妹妹的方式救姐姐，喊出“沈知雾”把姐姐拉回

### 薇薇安
- **定位**：旧圣历圣弥伦圣女 / 第三卷后现代国际交换生 / 莫天远房亲戚身份暂住莫家
- **当前认知**：知道黑骑士重新出现；知道莫宁梦影子与黑骑士相似；不知道莫天就是黑骑士
- **功能**：旧圣女体系入口、黑骑士传说线索、现代日常修罗场新变量
- **第三卷后提醒**：她离开圣弥伦是为了带走暴食定位锚点；表面端庄成熟，内心活泼吐槽；对莫宁梦亲近必须绑定“影子像黑骑士”这个理由

### 叶清棠
- **定位**：文学部高二学姐 / 现实压力源
- **当前进度**：014章正式把莫宁梦推上校刊与征文比赛；018章以校刊、值班、分享会占满宁梦时间；024章递水说“你最近太累了”，其善意压力已回收为宁梦失衡线的一部分
- **第二卷提醒**：她的压力来自真心欣赏，不来自恶意；越体面，越难拒绝
