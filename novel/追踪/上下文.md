## 力量体系设定（2026-05-18 全面修订）

> 完整文件见 [设定/世界观/力量体系.md](../设定/世界观/力量体系.md)

### 核心双能量体系
- **魔法少女**：使用**魔力**（纯净·守护·秩序）
- **魔女/梦魇**：使用**污秽**（混沌·侵蚀·破坏）

### 魔法少女等级（花周期）
| 等级 | 特征 | 对应敌人 |
|------|------|---------|
| **种子**（妹妹当前） | 基础能力觉醒 | 普通魔女 |
| **萌芽** | 魔力稳定输出，属性能力可用 | 变异魔女 |
| **绽放** | 能力全开，独当一面 | 编号魔女 |
| **满开** | 该属性的极致形态 | 完全体魔女 |

### 莫宁梦：影子属性
- **本质**：影子（Shadow Element）
- 参考：名侦探光之美少女·森亚露露卡／奥祕·暗影天使
- **能力**：影之操控 / 影之跃迁 / 影之感知 / 守护之影
- **光暗双生**：外表是光明魔法少女，本质是影子
- **当前等级**：种子期 → 迈向萌芽期

### 假面骑士形态体系
| 形态 | 变身音效 | 定位 |
|------|---------|------|
| **骑士（Knight）** | 噔噔↗噔噔↘噔噔↗ → **Knight** → 啊哈哈哈哈~ | 基础·最常用·拳拳到肉 |
| **暗夜（Nox）** | **Nox… Nox… Nox**（三回宣告） | 稍认真·影能冲击 |
| **暗影（Shadow）** | **Shadow** | 终极·几乎不用·完全暗影操控 |

- 变身载体：**Shadow Driver（影之驱动器）**，意念召唤
- 战斗风格：假面骑士拳拳到肉 vs 魔法少女远程魔法 → 两种画风

### 敌人区别
- **魔女**：魔法少女的敌人，有结界，无固定组织
- **梦魇**：骑士曾经的敌人，无结界，已基本消灭
- 魔法少女无法区分魔女和梦魇（认知限制）

## 当前基调和风格定位（2026-05-18 确定）
- **全篇基调**：轻松搞笑为主，不虐、不深沉、不强行走心
- **哥哥线**：无敌轻松碾压，战斗全是搞笑/吐槽风
- **妹妹线**：正常难度升级，但不致郁（参考魔圆设定但不走魔圆黑深残路线）
- **核心关系**：打打闹闹的兄妹日常。哥哥爱逗妹妹，妹妹爱粘哥哥，双向奔赴不自知
- **感情线**：妹妹单方面兄控 → 日常拉扯 → 甜向暧昧。不虐，全书结局揭示真相

## 角色定位速查

### 莫天
- 性格：沉稳 + 爱逗妹妹 + 偶尔腹黑
- 对妹妹：宠溺为主，嘴欠为辅
- 日常状态：一本正经说胡话，看妹妹被逗急是他最大乐趣
- 骑士初始形态：参考假面骑士 ZZZ Shadow（暗色系，阴影操控）

### 莫宁梦
- 性格：古灵精怪 + 话痨 + 兄控
- 对哥哥：重度依赖 + 不自觉的占有欲
- 日常状态：撒娇、跳脚、三句不离我哥
- 口头禅："哥——！你又欺负我！"

## 叙事结构要点

### 妹妹视角：标准魔法少女剧本
- 莫宁梦以为这个世界就是正常的魔法少女世界观
- 她不知道梦魇、不知道梦世界、不知道哥哥的秘密
- 她的剧情线：正常打怪 → 遇到困难 → 逐步成长 → 偶尔困惑（"这个魔女怎么怪怪的"）但不会深究
- **她的认知 = 读者的表层认知入口**

### 哥哥视角：无敌俯瞰 + 老父亲心态
- 莫天知道全部真相，全程上帝视角
- 看着妹妹一本正经当魔法少女 → 内心OS："加油加油……哎这都打不过？要不要帮忙……不行得让她自己来……"
- 操心妹妹的成长：像看孩子学走路，想扶又知道不能扶，憋得慌
- 偶尔出手：妹妹真搞不定的时候暗中清场，然后深藏功与名回去做饭

### 哥哥自己的小事件线
- 不是每天只围着妹妹转——他也有自己的事要处理
- 比如：梦世界残留的小麻烦、以前认识的人找上门、Shadow 形态的新能力摸索
- 但这些事件的难度对他而言依然是轻松级别，不走苦战路线
- **作用是丰富哥哥的角色形象**，不让他变成"只是为了妹妹存在的工具人"

## 写作注意事项
1. **搞笑优先**——遇到"走心还是搞笑"的选择，选搞笑
2. **兄妹互动是核心卖点**——战斗/剧情的推进不能挤占兄妹日常的篇幅
3. **妹妹的兄控表现要有层次**——从"依赖哥哥"到"意识到感情"是长线弧，前期不要太直白
4. **哥哥的腹黑要有度**——逗归逗，不能真的伤到妹妹的心
5. **战斗场面也要搞笑**——不能战斗时突然变严肃画风，保持吐槽/轻松感
6. **哥哥的老父亲心态要自然**——操心但不能写成说教，要用行动和内心OS而非唠叨

## ⭐ 核心写作红线：莫天的吐槽是全书第一卖点

- **每章至少2-3处莫天的精彩内心OS。** 这不是可选项，是必选项。
- 内心OS的风格：短、密、生活化。不要长篇大论，要一句见血。
- 内心OS的节奏：表面对话正常进行 → 内心突然弹幕 → 表面继续正常。反差越大越好笑。
- 好的例子："嗯，演技比上周进步了，从不及格升到40分了。"
- 不好的例子：莫天内心进行了一大段哲理性独白——这不是吐槽，这是旁白。
- **最终检验标准**：读者会不会因为莫天的内心OS笑出来。会→合格。不会→加强。
