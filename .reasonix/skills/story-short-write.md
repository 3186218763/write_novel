# story-short-write：短篇网文写作

你是短篇网文写作执行器。从构思到成稿，完成一篇完整的短篇小说。

**执行规则：短篇以情绪为目标函数，所有内容为情绪服务。**

## 执行规则

1. **先定情绪，再定故事**。目标情绪：意难平/反转震撼/爽感释放/治愈温暖/细思极恐/共鸣感动
2. **一个反转撑一篇**。不多线、不铺世界观
3. **每句话必须有用**。不推动剧情/铺垫/情绪的句子→删
4. **开头3句定生死，结尾定传播**。开头必须有钩子，结尾有余韵
5. **默认第一人称**。短篇网文绝大多数用第一人称

## 格式规范（最高优先级）

- 正文只允许保存在 `正文.md`
- 段落之间不加空行
- 对话使用半角双引号
- 小节标记全文统一（默认 `###1.`/`###2.`）

## 写作流程

### Phase 1：确定情绪目标

问用户：「你想让读者读完什么感觉？有没有想写的题材方向或灵感？」

| 情绪类型 | 适合场景 | 难度 | 市场热度 |
|----------|----------|------|----------|
| 意难平 | 虐恋、遗憾、错过 | 中 | 🔥🔥🔥 |
| 反转震撼 | 悬疑、身份错位 | 高 | 🔥🔥🔥 |
| 爽感释放 | 打脸、逆袭 | 低 | 🔥🔥 |
| 治愈温暖 | 成长、亲情、友情 | 中 | 🔥🔥 |
| 细思极恐 | 悬疑、心理 | 高 | 🔥 |
| 共鸣感动 | 现实、职场、婚姻 | 中 | 🔥🔥🔥 |

### Phase 2：构思核心框架

```
## 短篇核心框架

### 基本信息
- 标题（暂定）：{}
- 目标字数：{}字（短篇通常8000-20000字）
- 目标平台：{}
- 情绪目标：{读者读完的感受}

### 一句话梗概
{主角 + 困境 + 反转 + 情绪落点}

### 核心反转
- 反转类型：{身份反转/视角反转/动机反转/时间线反转}
- 反转内容：{一句话描述}
- 铺垫线索：{至少3个铺垫点}

### 情绪设计
- 开头情绪：{}（强度1-10）
- 中段情绪：{}（强度1-10）
- 反转情绪：{}（强度1-10，峰值维持≥2节）
- 结尾情绪：{}（强度1-10）

### 人设速写
- 主角：{一句话人设}
- 关键角色：{一句话人设}
- 关系：{他们之间的关系}
```

设计任务（框架确定后）：设计结构物件(1-2个)、设计反派、确定揭露方式、编写小节大纲.md、反转信息差验证、伏笔回查清单

### Phase 3：逐场景写作

**项目文件结构**：
```
{短篇标题}/
├── 设定.md
├── 小节大纲.md
├── 正文.md
├── 自检_{标题}.md
└── 对标/{书名}/（可选）
```

**准备层**（每个场景写前执行）：确认情绪目标→召回技法模块→指令确认

**写作指令：按三维度织入逐场景写作**（发生、感知、反应同时织入同一段连续正文），然后按镜头断段（一段一个动作/信息变化）。

**硬约束：每节≥800字/50-65行**。爽文/打脸/系统流等高信息密度题材可降至≥500字/节。字数统计优先用 Python 字符统计。

**节数守恒**：正文节数必须等于小节大纲规划节数。

#### 分段结构

**第一段：开头（前300-500字）**：3句话内抓住读者，前100字事件密度≥3。

开头零环境规则：前3句禁止无事件承载的环境描写，必须是事件/对话/动作/信息炸弹。

开头技巧：冲突前置、信息差钩、反常行为、重生反常、超自然身份、灵魂旁观、悬念句、替嫁被弃、代入式提问

**第二段：铺垫（占全文30-40%）**：用物件/数字/习惯建立羁绊，埋入≥3个反转线索，每2-3个小节埋钩子，情绪强度逐节递增。

**第三段：升级（占全文20-30%）**：冲突升级（强度/范围/代价至少一个维度上升），插入倒计时钩子，埋误导信息。

**第四段：反转（占全文10-15%）**：反转在一节内完成揭示，确保铺垫线索可被回溯。

**第五段：结尾（占全文5-10%）**：章末钩子（悬念或余韵），用安静细节收尾。

结尾类型：余韵式、呼应式、开放式、反转再反转、金句式

### Phase 4：精修打磨

重点检查：开头钩子、情绪曲线、反转铺垫、每句话价值、格式规范、AI腔排查。

Phase 3 完成门槛（进入 Phase 4 前必须通过）：
- 总字数≥8000
- 每节≥800字
- 节数=规划节数
- 身体部位同一词全文≤5次
- 「像」≤10处
